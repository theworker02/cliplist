# cliplist

Clip filesystem list paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/cliplist/

## Install / run

```bash
git clone https://github.com/theworker02/cliplist.git
cd cliplist
node src/cli.js
node --test
```
